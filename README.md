# Free Visitor Counter for GitHub Pages

A single-file compatibility demonstration for [counter.gratis](https://counter.gratis/?language=en).

## Publish

1. Create a public GitHub repository named `counter-gratis-demo`.
2. Upload `index.html` to the top level of the repository (not to a nested folder).
3. Commit the change.
4. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, your default branch (usually `main`), and `/ (root)`. Save.
5. GitHub displays the published URL in the Pages settings.

## Demo counter ID

The demonstration intentionally does not ship with somebody else's registered counter ID. Enter your own registered counter ID on the page to display a live counter, or replace the placeholder after you register a dedicated ID for this GitHub Pages site.

For production deployments, use the full embed snippet provided by counter.gratis. The HTML-only example has reduced tracking context.
